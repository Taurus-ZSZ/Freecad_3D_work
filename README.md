# Freecad_3D_work
freecad 3d design



install_freecad.ps1

使用方法：

1. 将FreeCAD_weekly-2025.11.02-Windows-x86_64-py311.7z 放到Downloads 目录下

2. 使用power shell 运行install_freecad.ps1

   1. 如果提示不能执行脚本请运行： Set-ExecutionPolicy RemoteSigned 

   2. 选择是

   3. 然后在powershell 中运行

      ./install_freecad.ps1

      脚本会自动安装freecad 到你的D 盘，并且自动在桌面创建快捷方式

3. 打开freecad 然后选择文件，新建文档->然后选择文件->导入，选择 Voron_2.4r2_Assembly_STEP.zip  这个文件打开看一下打开的快不快，3D 的视图卡不卡，比如缩放，旋转
